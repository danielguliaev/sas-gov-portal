# ТЗ: замечания к интерфейсу портала законов

**Проект:** `sas-gov-portal`  
**Статус документа:** сбор замечаний; требования не реализуются до отдельного указания пользователя.  
**Дата начала:** 04.11.2026.  
**Назначение:** накопительное ТЗ для последующих доработок пользовательского интерфейса законодательного портала. Новые замечания добавляются в этот документ, текущий код по ним не изменяется.

## UI-001. Блок «Прочие ресурсы» и отдельные сайты государственных органов

**Источник замечания:** сообщение пользователя со снимком навигационного блока портала от 04.11.2026.

### Текущее состояние

В боковой навигации портала законов отображаются переходы к следующим ресурсам:

1. Правительство штата
2. Судебная система
3. Законодательный орган
4. Город Лос-Сантос
5. Секретарь штата

### Требуемое состояние

Каждый из перечисленных ресурсов в будущем должен быть самостоятельным сайтом, а не отдельной страницей или разделом внутри законодательного портала.

На текущем этапе блок навигации рекомендуется обозначить заголовком **«Прочие ресурсы»**. До создания отдельных сайтов не следует предоставлять в этом блоке активные ссылки или маршруты к этим ресурсам. Заглушки, ведущие на страницы внутри портала законов, не должны восприниматься как отдельные государственные сайты.

Конкретные адреса сайтов, их дизайн, функционал и сроки реализации данным замечанием не определены; их следует согласовать отдельно перед разработкой.

### Критерии приёмки после разрешения на реализацию

- В навигации законодательного портала присутствует заголовок «Прочие ресурсы».
- Разделы «Правительство штата», «Судебная система», «Законодательный орган», «Город Лос-Сантос», «Секретарь штата» не открываются как внутренние страницы законодательного портала.
- Пока отдельные сайты не реализованы и их адреса не согласованы, в данном блоке нет активных ссылок на них.
- При создании отдельных сайтов интеграция ссылок рассматривается отдельным изменением.

**Приоритет:** не определён.  
**Состояние:** зафиксировано, **не реализовывать пока**.

## UI-002. Создание вложенных структурных элементов кодекса

**Источник замечания:** сообщение пользователя от 04.11.2026.

### Текущее состояние

В интерфейсе законодательного портала пользователь не может создавать внутри кодекса подразделы, части и другие элементы иерархии. Наличие или отсутствие соответствующих серверных API не устраняет проблему: требуемое управление недоступно через пользовательский интерфейс.

### Требуемое состояние

Добавить в интерфейс управления кодексом возможность создавать структурные элементы различных типов (в частности, части и подразделы), выбирать их место в иерархии, создавать дочерние элементы внутри уже существующих и прикреплять статьи к нужному уровню структуры. Допустимые типы, глубина вложенности и правила нумерации должны определяться настройками соответствующего кодекса и требованиями основного ТЗ; конкретные ограничения не вводить без согласования.

Создание и изменение структуры должно быть доступно только пользователям с соответствующими правами. Для остальных пользователей иерархия должна отображаться в режиме чтения.

### Критерии приёмки после разрешения на реализацию

1. В интерфейсе редактирования кодекса есть доступное уполномоченному пользователю действие создания структурного элемента.
2. Можно указать тип элемента, его заголовок/номер и родительский элемент либо корень кодекса в соответствии с настройками иерархии.
3. Созданный элемент отображается в дереве кодекса на выбранном уровне и доступен для добавления вложенных элементов или статей, если это разрешено структурой.
4. После обновления страницы созданная иерархия сохраняется и правильно отображается читателям.
5. Неуполномоченный пользователь не может изменять структуру; ошибки валидации показываются понятным сообщением.

**Приоритет:** не определён.  
**Состояние:** зафиксировано, **не реализовывать пока**.
