# Реализация ТЗ 1.0: запуск, контракты и ограничения

## Назначение

Пилотная версия законодательной сети вымышленного штата Сан-Андреас. Все автоматически создаваемые статьи — **демонстрационные**, не действующие юридические нормы. Переводы иных законов из пользовательских файлов не импортируются автоматически.

## Локальный запуск

Python 3.11+:

    python -m venv .venv
    source .venv/bin/activate
    python -m pip install -e ".[test]"
    uvicorn app.main:app --reload
    pytest -q

Сайт доступен по адресу http://127.0.0.1:8000, интерактивная документация API — http://127.0.0.1:8000/docs, OpenAPI — /openapi.json. На Windows используется соответствующий скрипт активации venv. Для локального входа выберите тестовую роль в верхней панели.

## Архитектура

Сервер: FastAPI, SQL-модель SQLite/WAL (db/001_initial.sql), транзакции BEGIN IMMEDIATE, ограничения уникальности и внешних ключей. Русскоязычный адаптивный интерфейс: web/index.html, web/style.css, web/app.js. Постоянные ID независимы от юридических номеров. Новые юридические редакции добавляются отдельными строками со снимками категорий, полей, санкций и связей.

Переменные окружения: DATABASE_PATH, APP_ENV, AUTH_MODE, OIDC_ISSUER, OIDC_AUDIENCE, OIDC_JWKS_URL, OIDC_ROLES_CLAIM. В production демонстрационная авторизация запрещена, допускается только OIDC RS256/JWKS. Формат конкретного внешнего IAM, интерактивный вход и конечные домены требуют интеграции с другой командой.

## Основной API

Базовое чтение (требуется аутентификация): GET /api/v1/jurisdictions, /portals, /codes, /codes/{code_id}/tree, /codes/{code_id}/root/articles, /nodes/{node_id}/articles, /articles/{article_id}, /articles/{article_id}/position, /articles/{article_id}/adjacent, /articles/{article_id}/relations, /search, /precedents, /portal-publications, /bills. Выдача статей содержит курсор продолжения next_cursor.

Для lawyer/superadmin доступны история версий и снимки конкретной редакции, поля категорий, расширенные поисковые фильтры, /me/favorites, /me/notifications, примечания к выделению текста в определённой редакции. Настройки масштаба текста хранятся через /me/preferences. Обычным читателям юридические расширенные поля сервер не возвращает.

Запись superadmin: POST /codes, /codes/{code_id}/hierarchy-types, /codes/{code_id}/nodes, /articles, /articles/{id}/revisions, /relation-types, /relations, /categories, /categories/{id}/fields, /category-fields/{id}/options; PATCH /hierarchy-types/{id}, /nodes/{id}, /category-fields/{id}, /field-options/{id}. Предусмотрены предпросмотр и подтверждение переноса узла, пересортировка, предпросмотр и удаление типов иерархии с поднятием детей, каскадное архивирование/восстановление, в том числе атомарная замена конфликтующей статьи.

Исключительное редактирование: POST /articles/{id}/edit-lock создаёт блокировку конкретной сессии и выдаёт токен; /edit-lock/heartbeat продлевает владение; DELETE /edit-lock освобождает; /edit-lock/revoke требует подтверждение и допускает только собственную блокировку superadmin. Сохранение проверяет lock_token, editor_session_id и base_revision_id, серверное истечение блокировки — 5 минут.

Официальные публикации portal_publisher: POST /portal-publications и /portal-publications/{id}/publish. Только публикация не меняет текст кодекса. Library_editor/superadmin может проверить публикацию через /editorial-reviews и /editorial-reviews/{id}/confirm: нужны блокировка и подтверждённый консолидированный текст; происхождение сохраняется в новой редакции. Судебные прецеденты квалифицируются через /portal-publications/{id}/precedent. Законопроекты и голосования доступны отдельными маршрутам /bills; допустимые переходы конфигурируются через BILL_TRANSITIONS_JSON и изначально демонстрационные.

## Инварианты

Уникальность действующего номера статьи проверяется в пределах кодекса, в том числе по нормализованному номеру, без влияния на архивные номера. У обвинения должен быть один класс felony/misdemeanor/infraction; произвольные поля необязательны. Наличие санкции добавляет категорию «Мера наказания», все отсутствующие границы санкций остаются null, а не нулём. Одна статья наказания может быть связана не более чем с одним внешним обвинением в активном состоянии. Архивирование отключает связи без автоматической повторной активации; история изменений сохраняется. Рискованные массовые операции требуют актуальный preview_hash, confirm:true и заголовок Idempotency-Key; для конфликта номера при восстановлении отдельно необходим confirm_swap:true. HTML очищается на сервере.

## Статус и ограничения пилотной реализации

Это функциональная база, **не** удостоверенная полнота реализации всех 20 приёмочных сценариев и **не** production-ready продукт. Существующий UI охватывает чтение, поиск, избранное, уведомления, базовое редактирование и портальные публикации, но не содержит исчерпывающего управления типами иерархии, юридическими связями, архивными массовыми операциями, всеми специальными полями и юридическими комментариями. Ряд функций доступен через API/Swagger, а не через полноценные отдельные экраны.

Точное восстановление Back/Forward при всех вариантах динамической подгрузки, пользовательское подавление раскрытия веток, масштабирование сверхбольших кодексов и виртуализация требуют дополнительных UI/приёмочных испытаний. Отсутствуют утверждённый внешний контракт IAM, реальные государственные регламенты, полный межпортальный event bus, инфраструктура PostgreSQL/multi-instance, регулярные проверяемые бэкапы, мониторинг, rate limiting, эксплуатационные миграции отката и полный аудит безопасности. Внедрение с реальными учётными записями не допускается до закрытия этих вопросов.

Автоматические тесты расположены в tests/, GitHub Actions — .github/workflows/tests.yml. Результат CI относится к конкретному commit SHA.
