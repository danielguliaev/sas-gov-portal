Проверяются закрытость чужих черновиков, отсутствие обхода через старые маршруты, подтверждение соавторства, конфликт редакций, оба срока комитетского рассмотрения, окончательный Not Pass, новые циклы Held, снимки повесток, правила подсчёта, кворум, решающий голос, каскадное отсутствие, смена голоса и закрытие по сроку. Проверки административных исправлений включают отдельное утверждение итогов и запрет перезаписи более новой повестки старым заседанием.

`python -m scripts.verify_senate` прошёл полный процесс на временной базе:

1. Два проекта с поправками к существующей статье получили по две редакции и подтверждённого соавтора.
2. Консультант предоставил отчёты, председатель сформировал повестки и сохранил решения.
3. Pro Tempore опубликовал пленарную повестку. Проверены обычный голос, каскадное отсутствие и последующее восстановление присутствия.
4. После срока оба проекта приняты, стенограмма сохранена, PDF и JSON сформированы.
5. Содержимое и редакции статей библиотеки совпали с состоянием до проверки.

Экспорты сохраняются в исключённой из Git папке `.senate-preview/acceptance`. PDF проекта содержит три страницы, PDF заседания одну. После преобразования в изображения проверены кириллица, переносы длинного названия, журнал рассмотрения, колонтитулы и нумерация. Тест часового пояса проверяет летнее время Europe/Berlin. На работающем локальном сервере и отдельной базе проверены:

- создание черновика, выбор статьи библиотеки, поправка, новая редакция и подача в Rules Committee;
