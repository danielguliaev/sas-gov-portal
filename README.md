# Правовая библиотека штата Сан Андреас

Система законодательных ресурсов вымышленного штата Сан-Андреас по ТЗ 1.0 (04.11.2026).
Стартовые кодексы и тексты — демонстрационные, а не действующее право.

## Windows: запуск двойным нажатием

Для локального запуска портала из Проводника используйте файл **start_portal.bat** в корне репозитория. Его можно запускать двойным нажатием. Скрипт:

- Проверяет Python 3.12 (или 3.11); при его отсутствии показывает инструкцию установки.
- Создаёт собственное виртуальное окружение `.venv-portal`, не затрагивая прежнее `.venv`.
- Устанавливает зависимости при первом запуске и повторно использует их после этого.
- Запускает сервер на 127.0.0.1:8000 и открывает страницу в браузере, когда сервер готов.
- Если сервер уже запущен, просто открывает существующую страницу.

При первом запуске нужен интернет. Для остановки сервера закройте окно консоли или нажмите Ctrl+C. Если файл находится в «Загрузках», скрипт также попробует найти проект в `%USERPROFILE%\sas-gov-portal`; для других расположений поместите файл непосредственно в корень проекта.

Скрипт предназначен только для локальной демонстрационной версии Windows, не для публикации в интернете.

## Что можно делать в библиотеке

После входа читатель видит кодексы, отдельные нормативные акты, иерархические разделы, карточки статей, судебные прецеденты и поиск. Юрист дополнительно работает с профессиональными фильтрами (уголовные классы, санкции, пользовательские поля), архивом редакций, научными примечаниями и личным избранным. Суперадминистратор создаёт кодексы и разделы, настраивает категории и поля, вручную управляет юридическими связями и структурным порядком, архивирует и восстанавливает материалы с предварительным просмотром.

Административная область: `http://127.0.0.1:8000/admin`. Самостоятельные нормативные акты: `/acts`. Структура кодекса: `/admin/hierarchy`. Категории: `/admin/categories`. Отношения: `/admin/relations`. Архив: `/admin/archive`. Журнал: `/admin/audit`.

Исторические редакции сохраняют снимки названий юридических справочников начиная со схемы v2. Внешние ведомственные публикации не становятся нормативными актами до явного подтверждения суперадминистратором.

## Восстановление БД и эксплуатация

`scripts/db_maintenance.py` поддерживает проверяемую резервную копию SQLite, восстановление с аварийной резервной копией, проверку целостности и запуск миграций. Перед восстановлением сервер нужно остановить. Полный порядок, параметры OIDC и настройки сервисного API описаны в [docs/OPERATIONS.md](docs/OPERATIONS.md).

Для разработки поддерживаются только три видимые роли библиотеки. Внешняя авторизация OIDC реализована как настраиваемый PKCE-адаптер; окончательное подключение требует контракт поставщика IAM и совместные испытания. Самостоятельные государственные сайты отложены по прямому решению заказчика. Промышленная инфраструктура и полная приёмка по ТЗ всё ещё требуют отдельной проверки.

## Быстрый запуск

Требуется Python 3.11+.

    python -m venv .venv
    source .venv/bin/activate
    pip install -e ".[test]"
    uvicorn app.main:app --reload

Сайт: http://127.0.0.1:8000
OpenAPI: http://127.0.0.1:8000/docs
Тестирование: pytest -q

В пользовательском интерфейсе библиотеки доступны три роли: читатель (user), юрист (lawyer), суперадминистратор (superadmin). Внутренние серверные роли ведомственных процессов сохранены до разработки отдельных сайтов.
В продуктивном окружении тестовые аккаунты отключены и требуется внешний OIDC.

Информация об API, серверной модели, ограничениях и необходимых доработках: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

**Статус:** пилотный функциональный фундамент, не завершённая промышленная реализация всего ТЗ 1.0.

Пользовательские доработки по замечаниям UI-001…UI-008: [docs/UI_FEEDBACK_TZ.md](docs/UI_FEEDBACK_TZ.md). Для работы со структурой кодекса выберите роль «Суперадминистратор», откройте кодекс и воспользуйтесь кнопками «Добавить тип уровня» и «Добавить часть / раздел».
